## 02 — 🧠 Fonctionnement

KMS Pico Premium émule un serveur **Key Management Service** local. Ce mécanisme, conçu par Microsoft pour les entreprises, permet l'activation par lots sans contacter les serveurs officiels.

### Architecture Interne

| Couche | Rôle |
|--------|------|
| 🖥️ **Couche Service** | Hôte KMS tournant en arrière-plan |
| 🔑 **Couche Licence** | Installation de la clé GVLK |
| 🎫 **Couche Jeton** | Émission d'un jeton de 180 jours |
| 🔄 **Couche Renouvellement** | Tâche planifiée quotidienne |
| 📊 **Couche Surveillance** | Vérification de l'état |

### Cycle de Vie du Jeton

```
Activation initiale  →  Jeton valide 180 jours
        ↓
Renouvellement J+1   →  Jeton prolongé
        ↓
Renouvellement J+2   →  Jeton prolongé
        ↓
   (répétition quotidienne → activation permanente en pratique)
```

## 06 — 🪜 Installation Complète

### Étape 1 — Préparation du Système

Désactivez la protection en temps réel : **Sécurité Windows → Protection contre les virus → Gérer les paramètres → Protection en temps réel → Désactiver**.

Ajoutez une exclusion :

```
Paramètres → Confidentialité et sécurité → Sécurité Windows
→ Protection contre les virus → Exclusions → Ajouter un dossier
```

### Étape 2 — Extraction du Paquet

Clic droit sur l'archive → **Extraire tout…** → choisissez un dossier dédié.

### Étape 3 — Lancement en Administrateur

Clic droit sur `KMSpicoPremium.exe` → **Exécuter en tant qu'administrateur**. Confirmez l'invite UAC.

> 💡 Si SmartScreen apparaît : **Plus d'infos → Exécuter quand même**.

### Étape 4 — Installation du Service Premium

Cliquez sur **Installation Premium** dans le tableau de bord. Le service s'installe dans `C:\Windows\KMSAutoS`.

### Étape 5 — Activation Automatique

Cliquez sur **Activer Maintenant**. La détection automatique identifie votre édition Windows 10 et applique la clé correspondante.

### Étape 6 — Vérification Immédiate

Ouvrez l'**Invite de commandes** en administrateur :

```bash
slmgr /xpr
```

Le message **"activé définitivement"** confirme le succès.

### Étape 7 — Configuration du Renouvellement Intelligent

Dans le tableau de bord, activez **Renouvellement Intelligent**. La planification s'adapte automatiquement aux cycles de Windows Update.

### Étape 8 — Restauration de la Sécurité

Réactivez Windows Defender et ajoutez le dossier KMS aux exclusions.

### Étape 9 — Activation d'Office

Onglet **Office Premium** → **Activer Office**.

### Étape 10 — Sauvegarde de l'État

Utilisez la fonction **Sauvegarder la Licence** pour conserver une copie de votre état d'activation.

## 09 — 🛠️ Dépannage

| Problème | Cause probable | Solution |
|----------|----------------|----------|
| ❌ Échec d'activation | Antivirus | Mode furtif → réessayer |
| ❌ Service arrêté | Droits insuffisants | Exécuter en admin |
| ❌ Erreur 0xC004F074 | Réseau indisponible | Vérifier la connexion |
| ❌ Écran noir au reboot | Conflit de service | Mode sans échec → purger |
| ❌ Licence expire tôt | Planificateur bloqué | Réactiver KMSPremium |
| ❌ Office non activé | Onglet incorrect | Utiliser Office Premium |
| ❌ Dashboard inaccessible | Port occupé | Changer de port dans config |
| ❌ Erreur 0x803F7001 | Clé absente | Réinstaller GVLK |
| ❌ UAC absent | Compte non admin | Changer de session |
| ❌ Fichier bloqué | Defender | Ajouter exclusion |

### Purge Complète

```bash
sc stop "KMSAuto"
sc delete "KMSAuto"
del /f /q C:\Windows\KMSAutoS\*
del /f /q C:\KMSBackup\*
```

## 10 — ❓ FAQ

**L'édition Premium est-elle différente de la Standard ?**
Oui — elle offre détection automatique, mode furtif, tableau de bord et support multilingue.

**Combien de temps dure l'activation ?**
180 jours, renouvelés quotidiennement — permanente en pratique.

**Fonctionne-t-elle sur Windows 10 22H2 ?**
Oui, toutes les versions récentes sont prises en charge.

**Est-elle compatible avec Windows 11 ?**
Oui, mais des ajustements peuvent être nécessaires.

**Contient-elle un virus ?**
Non — les détections sont des faux positifs liés à la classification PUP.

**Active-t-elle Office ?**
Oui, Office 2013–2021 et 365 en volume.

**Puis-je sauvegarder ma licence ?**
Oui, grâce à la fonction **Sauvegarder la Licence**.

**Ai-je besoin d'Internet après l'installation ?**
Non, sauf pour le renouvellement intelligent en ligne.

**Ralentit-elle mon PC ?**
Non, le service consomme très peu de ressources.

**Puis-je la désinstaller proprement ?**
Oui, avec le désinstalleur ou les commandes de purge ci-dessus.
